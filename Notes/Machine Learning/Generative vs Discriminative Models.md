# Generative vs Discriminative Models

Two major approaches exist for probabilistic classification.

---

# Generative Models

Model:

$$
p(x,y)
$$

Examples:

- LDA
- Naive Bayes

---

# Advantages

- can generate data
- handle missing data
- useful for semi-supervised learning
- probabilistic interpretation

---

# Weaknesses

Performance degrades if modeling assumptions are incorrect.

---

# Discriminative Models

Model:

$$
p(y|x)
$$

directly.

Examples:

- logistic regression
- neural networks

---

# Advantages

Usually achieve higher classification accuracy.

---

# Weaknesses

Do not model data generation itself.

---

# Main Insight

Generative models explain how data is produced.

Discriminative models focus only on decision boundaries.
