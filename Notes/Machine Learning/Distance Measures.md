# Definition

Euclidean distance ($L_2$):

$$\Large
d(u,v) =
\sqrt{\sum_i (u_i - v_i)^2}
$$

$L_1$ norm:

$$\Large
d(u,v) =
\sum_i |u_i - v_i|
$$

$L_\infty$ norm:

$$\Large
d(u,v) =
\max_i |u_i - v_i|
$$

Angle (cosine similarity):

$$\Large
\cos \alpha =
\frac{u^T v}{\|u\| \|v\|}
$$

Mahalanobis distance:

$$\Large
d(u,v) =
\sqrt{(u-v)^T \Sigma^{-1} (u-v)}
$$

Other distances:

- Hamming distance  
- Edit distance
