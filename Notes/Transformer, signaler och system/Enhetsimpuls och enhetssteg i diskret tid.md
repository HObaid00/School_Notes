# Enhetsimpuls och enhetssteg i diskret tid

Diskreta standardsignaler spelar samma roll som delta och steg i kontinuerlig tid.

## Definitioner
$$\Large
\begin{cases}
δ[n] = 1 \text{ för } n = 0, \text{ annars } 0 \\
σ[n] = 1 \text{ för } n ≥ 0, \text{ annars } 0
\end{cases}
$$
## Komentar
Dessa definieras explicit i Z-transform del 1.
