# DTFS

DTFS är Fourierserie för tidsdiskreta periodiska signaler.

## Kärna
För en sekvens med period N räcker det med N distinkta basfunktioner.

## Form
$$\Large
x[n] = \sum_{k=0}^{N-1} X[k] e^{jkΩ_0 n}
\text{ där } Ω_0 = \frac{2π}{N}$$

## Komentar
DTFS introduceras som diskret motsvarighet till Fourierserier för effektsignaler.
