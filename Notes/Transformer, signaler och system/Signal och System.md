# Signal och system

En signal är en tidsberoende insignal som bearbetas av ett system och ger en utsignal.

## Kärna
Ett system beskriver en relation mellan insignal och utsignal:
```
		-----
x(t) -> | S | -> y(t)
		-----
```
## Exempel
- mänsklig kropp: matintag -> blodsockernivå
- elektrisk krets: spänning in -> spänning över komponent
- massa-fjäder-dämpare: kraft -> position
