# Heavisides stegfunktion

Stegfunktionen modellerar ett abrupt påslag vid t = 0.

## Definition
$$\Large
\begin{cases}
σ(t) = 0 \text{ för } t < 0 \\
σ(t) = 1 \text{ för } t ≥ 0
\end{cases}
$$
## Användning
Används för att beskriva signaler som startar vid en viss tidpunkt.

## Komentar
Stegfunktionen introduceras som standardsignal och kopplas till delta genom derivation.
