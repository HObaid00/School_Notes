# LTI-system

LTI står för linjära tidsinvarianta system.

## Kärna
Ett LTI-system uppfyller:
- [[Linjäritet]]
- [[Tidsinvarians]]

## Betydelse
För LTI-system kan man använda överföringsfunktioner, impulssvar och faltning.

## Komentar
LTI-begreppet definieras explicit i både kontinuerlig och diskret version.
