# Linjäritet

Ett system är linjärt om superpositionsprincipen gäller.

## Kärna
Om
$\Large x1 \rightarrow y1$
$\Large x2 \rightarrow y2$

så gäller
$\Large a x_1 + b x_2 \rightarrow a y_1 + b y_2$

## Varför viktigt
Linjäritet gör att komplicerade insignaler kan delas upp i enklare delar som analyseras separat.
