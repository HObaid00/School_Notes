# Cloud Computing vs Edge Computing

**Cloud computing** centralizes compute and storage in data centers. It is good for large-scale analytics, machine learning, central coordination, and long-term storage.

**Edge computing** moves selected computation closer to the devices. It is good for real-time processing, local control, data filtering, and immediate visualization.

A simple distinction is:

$$\Large
\text{Cloud} = \text{global view + large resources}
$$

$$\Large
\text{Edge} = \text{local view + fast response}
$$

Example:

- Cloud: train a model from millions of measurements.
- Edge: run the trained model locally to detect an event in real time.

In IoT projects, cloud and edge are usually complementary rather than mutually exclusive.
