# ICMPv6

**ICMPv6** is the control-message protocol for IPv6.

It is used for error reporting and network control functions. Neighbor Discovery is built on ICMPv6 messages.

An ICMPv6 message contains fields such as:

- Type
- Code
- Checksum
- Message-specific data

ICMPv6 is not just optional diagnostics. It is a necessary part of IPv6 operation.
