# RIOT OS

**RIOT** is an operating system for low-end IoT devices. It is designed to feel more like normal systems programming than very specialized sensor-network systems.

RIOT supports:

- Microcontroller-based IoT devices
- Multi-threading
- C and C++
- IPv6 networking
- POSIX-like APIs where possible
- Portability across hardware platforms

RIOT is useful when the project needs a more familiar programming model while still targeting constrained embedded devices.

Compared with tiny event-only systems, RIOT may use more resources but can be easier to develop with.
