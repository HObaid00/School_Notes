# Edge Placement Options

Edge computing can be placed at different points in the system.

Possible locations include:

- Directly on the IoT device
- On a local gateway
- In a local edge server
- Inside a vehicle
- At a cellular base station
- In a regional data center

The closer the edge is to the device, the lower the latency can be. But closer edge nodes usually have less compute power and less global information.

A useful trade-off is:

$$\Large
\text{closer to device} \Rightarrow \text{lower latency, less global context}
$$

$$\Large
\text{closer to cloud} \Rightarrow \text{more resources, higher latency}
$$
