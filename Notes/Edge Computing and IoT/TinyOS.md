# TinyOS

**TinyOS** is an early operating system and programming environment for wireless sensor networks.

TinyOS is strongly event-driven. It was designed for tiny devices with very limited memory and energy.

Important ideas in TinyOS include:

- Components instead of large monolithic applications
- Events and commands
- Cooperative execution
- Very small memory footprint

TinyOS shows why IoT software often differs from normal PC software: when memory and energy are extremely limited, the programming model must be designed around those limits.
