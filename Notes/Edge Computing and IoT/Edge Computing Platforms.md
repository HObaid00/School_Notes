# Edge Computing Platforms

Edge applications can run on different platforms depending on required resources.

Examples:

- Microcontrollers for very low-power local logic
- Raspberry Pi or similar devices for gateways
- Industrial PCs for local control
- Edge servers for heavier processing
- Cloud-managed edge platforms for deployment and monitoring

Software may include Linux, containers, IoT operating systems, message brokers, web servers, databases, and REST APIs.

A common architecture is to use constrained devices for sensing and a Linux-based edge node for aggregation and Internet connectivity.
