# IPv4 vs IPv6 Addressing

IPv4 addresses are commonly written in dotted decimal notation:

```text
172.16.254.1
```

IPv6 addresses are written in hexadecimal groups:


```text
2001:0db8:ac10:fe01:0000:0000:0000:0000
```

IPv6 allows abbreviation of zeros:

```text
2001:db8:ac10:fe01::
```

The basic difference is address length:

$$\Large
IPv4 = 4 \cdot 8 = 32\text{ bits}
$$

$$\Large
IPv6 = 8 \cdot 16 = 128\text{ bits}
$$
