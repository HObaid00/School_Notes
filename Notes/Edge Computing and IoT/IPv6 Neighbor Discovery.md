# IPv6 Neighbor Discovery

**Neighbor Discovery (ND)** is an IPv6 mechanism for managing the local link environment.

ND helps with:

- Discovering neighboring nodes
- Finding routers
- Resolving link-layer addresses
- Detecting unreachable neighbors
- Supporting stateless address autoconfiguration

It can be understood as a one-hop local protocol. It helps devices learn who is nearby and how to send packets on the local link.

In constrained IoT networks, standard ND may be too heavy, so 6LoWPAN uses optimized neighbor discovery mechanisms.
