# Connecting Things: Network Architecture

IoT communication connects sensors, devices, edge nodes, cloud systems, and external services.

A typical architecture is:

$$\Large
\text{sensors/devices} \leftrightarrow \text{edge gateway} \leftrightarrow \text{cloud} \leftrightarrow \text{systems}
$$

The connection technology depends on range, data rate, power budget, cost, and deployment environment.

Examples of wireless technologies include:

- IEEE 802.15.4 / Zigbee
- Bluetooth Low Energy
- Wi-Fi
- RFID
- NFC
- Cellular networks
- LoRaWAN and other low-power wide-area technologies
