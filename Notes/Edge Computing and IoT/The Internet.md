# The Internet

The Internet is a global system of interconnected packet-switched networks using the Internet Protocol.

It consists of many smaller networks operated by different organizations. These networks interconnect using standardized protocols.

Important organizations:

- **IETF** standardizes many Internet protocols.
- **ICANN** coordinates unique identifiers such as domain names, IP addresses, and protocol parameters.
- **IGF** discusses Internet governance issues.

The key technical idea is packet switching: data is split into packets, and each packet is forwarded through networks toward its destination.
