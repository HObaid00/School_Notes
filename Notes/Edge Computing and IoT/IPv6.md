# IPv6

**IPv6** is the next-generation Internet Protocol designed to replace IPv4.

Important IPv6 features:

- 128-bit addresses
- Larger address space
- Hierarchical addressing
- Stateless address autoconfiguration
- Simpler base header design
- Extension headers for optional features

An IPv4 address has $32$ bits, while an IPv6 address has $128$ bits.

$$\Large
|IPv4| = 2^{32}
$$

$$\Large
|IPv6| = 2^{128}
$$

The huge IPv6 address space is especially useful for IoT because many devices may need unique addresses.
