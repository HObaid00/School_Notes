# IPv6 Address Structure

An IPv6 address can be constructed from a network prefix and an interface identifier.

Simplified structure:

$$\Large
\text{IPv6 address} = \text{network prefix} + \text{interface ID}
$$

For local unicast addresses, the address may include:

- Prefix
- Global ID
- Subnet ID
- Interface ID

The interface ID can sometimes be derived from a link-layer identifier, such as an Ethernet address, although privacy extensions may use randomized identifiers.
