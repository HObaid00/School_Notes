# Learning Objectives for IoT and Edge Systems

A developer of IoT and edge systems should understand:

- The limits of IoT devices in CPU, memory, storage, communication, and power.
- How to design software for constrained devices.
- How to split work between IoT devices, edge nodes, and the cloud.
- How to use Internet protocols and service architectures in constrained environments.
- How to handle security, privacy, deployment, and operations.

The long-term vision is to make IoT software development feel more like normal Internet software development, while still respecting embedded constraints.
