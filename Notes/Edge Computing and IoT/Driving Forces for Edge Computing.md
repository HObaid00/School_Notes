# Driving Forces for Edge Computing

Edge computing is motivated by applications where sending all data to the cloud is inefficient or impossible.

Important driving forces are:

- **High bandwidth demand**, such as video surveillance, connected vehicles, and industrial monitoring.
- **Fast response time**, such as health care alarms, financial transactions, and vehicle-to-X warnings.
- **Reliability**, because local systems may need to continue operating when cloud access is interrupted.
- **Privacy**, because some data should not leave the local environment.

**Example:** A red-light warning system for vehicles cannot wait for slow cloud round trips. It needs local processing near the road or vehicle.

**Another Example:** Cars communicating with each other, can't do it via a centralized cloud, it would be to much network traffic.
