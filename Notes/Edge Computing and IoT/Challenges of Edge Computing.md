# Challenges of Edge Computing

Edge computing introduces new system-management problems because compute resources are distributed across many local nodes.

Important challenges include:

- **Configuration**: many devices must be configured correctly.
- **Deployment**: software must be installed on heterogeneous edge nodes.
- **Updates**: devices need secure and reliable updates.
- **Failures**: edge nodes may disconnect, crash, or lose power.
- **Consistency**: edge and cloud data must stay synchronized.
- **Mobility**: mobile devices may need handover between edge nodes.
- **Security**: attackers may physically access edge devices.

Containers can help package edge applications, but they also add overhead and management complexity.
