# Edge Computing

**Edge computing** places computation close to the source of the data instead of sending everything directly to a remote cloud server.

A common IoT architecture is:

$$\Large
\text{IoT device} \rightarrow \text{Edge node / Gateway} \rightarrow \text{Cloud}
$$

The edge node can perform local processing, filtering, caching, aggregation, and fast control decisions.

Edge computing is useful because it can:

- Reduce latency because decisions are made near the device.
- Save bandwidth because not all raw data must be sent to the cloud.
- Improve privacy because sensitive data may stay local.
- Keep systems partially functional even when cloud connectivity is weak.

Example: A connected car may generate video, radar, map, and sensor data. Sending all raw data to the cloud is expensive and slow, so some processing should happen inside the car or near the road infrastructure.
