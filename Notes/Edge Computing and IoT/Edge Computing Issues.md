# Edge Computing Issues

Edge computing creates architectural issues that do not appear in a simple cloud-only system.

Important issues:

- Edge nodes may only see local data.
- Mobile clients may move between edge nodes.
- Edge nodes may need to coordinate with each other.
- Some state must be synchronized with the cloud.
- Local failures can affect nearby devices.

Example: In a connected-car scenario, an edge node near one road segment may know local traffic conditions, but it may need to exchange information with neighboring edge nodes to support handover.
