# Lecture 1 Big Picture

The main idea of the first lecture is that IoT systems are not just small web applications. They combine constrained devices, local edge processing, wireless communication, and cloud services.

A practical IoT project usually needs to answer these questions:

1. What physical data should be sensed?
2. What should be processed on the device?
3. What should be processed at the edge?
4. What should be sent to the cloud?
5. How much power, bandwidth, and latency can the system afford?

A good mental model is:

$$\Large
\text{IoT design} = \text{hardware constraints} + \text{network constraints} + \text{software architecture}
$$
