# Symmetric Matrices

A square matrix $A \in \mathbb{R}^{n \times n}$ is symmetric if:

$$\Large
A = A^T
$$

It is anti-symmetric if:

$$\Large
A = -A^T
$$

Any square matrix can be decomposed into symmetric and anti-symmetric parts:

$$\Large
A = \frac{1}{2}(A + A^T) + \frac{1}{2}(A - A^T)
$$

## Key Idea
- $\frac{1}{2}(A + A^T)$ is symmetric
- $\frac{1}{2}(A - A^T)$ is anti-symmetric

## Notation
The set of all symmetric $n \times n$ matrices is denoted:

$$\Large
S^n
$$
