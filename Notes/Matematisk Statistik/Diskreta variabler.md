## Definition
Villkoret för diskreta är att 
$$\Large
S = \{0, 1, 2, \dots \} = \mathbb{N}
$$
alttså uppräknebart och heltal.
## Fall
$$\Large \begin{array}s
P(X = k) = p(k)   \\
P(X \in S) = \sum_{k=0}^\infty p(k) = 1\\
\text{Vanligt är: } P(X \leq m) = \sum_{k=0}^m p(k) \in [0, 1] \\
\text{och } P(a \leq X \leq b) = \sum_{k=a}^b p(k) = P(X \leq b) - P(X\leq a-1)\in [0, 1] \\
\end{array}
$$

## OBS!
$$\Large
P(X\leq k) \not= P(X < k)
$$
för diskreta variabler.
