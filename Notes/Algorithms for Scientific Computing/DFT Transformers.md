
| **DFT and Symmetry** | **INPUT**                  | **TRANSFORM**                       |
| -------------------- | -------------------------- | ----------------------------------- |
| **real symmetry**    | $\Large f_n \in \mathbb R$ | **Real DFT (RDFT**)                 |
| **even symmetry**    | $\Large f_n = f_{-n}$      | **Discrete Cosine Transform (DCT)** |
| **odd symmetry**     | $\Large f_n = -f_{-n}$     | **Discrete Sine Transform (DST)**   |
|                      |                            |                                     |
| **"QUARTER-WAVE"**   | **INPUT**                  | **TRANSFORM**                       |
| **even symmetry**    | $\Large f_n = f_{-n-1}$    | **QW-DCT**                          |
| **odd symmetry**     | $\Large f_n = -f_{-n-1}$   | **QW-DST**                          |
