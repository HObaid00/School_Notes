
# Matematisk statistik

Matematisk statistik indelas i:

- **sannolikhetslära**
- **statistik**

### Sannolikhetslära

- att räkna med slumpen  
- slumpen = ofullständig information
- delområde till matematiken (måtteori / integrationsteori)
- före observationer
- grunden till statistiken

### Statistik

- efter observationer
- hur man använder sannolikhetslagarna
- räkna med gjorda observationer
- dra slutsatser om den sinnliga världen
