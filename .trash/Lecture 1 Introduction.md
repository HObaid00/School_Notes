# Supervised Learning

Given training samples:

$$\Large
X_{\text{train}} = \{x_1, \dots, x_N\} \subseteq \mathcal{X}
$$

with corresponding targets:

$$\Large
y_{\text{train}} = \{y_1, \dots, y_N\} \subseteq \mathcal{Y}
$$

Find a function:

$$\Large
f : \mathcal{X} \to \mathcal{Y}
$$

such that:

$$\Large
f(x_i) \approx y_i
$$

Using \( f \), make predictions for test data:

$$\Large
\hat{y}_{\text{test}} = f(X_{\text{test}})
$$

---

## Supervised Learning: Classification

If the targets $( y_i )$ represent **categories**, the problem is called **classification**.
### Examples

- Handwritten digit recognition  
- Transaction classification (fraud, valid)  
- Object classification (cat, dog, hotdog, …)  
- Cancer detection  

![[Pasted image 20260226164542.png|697]]

---

## Supervised Learning: Regression

If the targets ( $y_i$ ) represent **continuous numbers**, the problem is called **regression**.

### Examples

- Stock market prediction  
- Demand forecasting  
- User involvement measurement  
- Revenue analysis

# Unsupervised Learning

Unsupervised learning is concerned with finding structure in **unlabeled data**.

## Typical Tasks

- **Clustering**  
  - Group similar objects together  

- **Dimensionality Reduction**  
  - Project high-dimensional data to lower dimensions

# Other Categories

- **Reinforcement learning**  
  - Learning by interacting with a dynamic environment  
  - Goal: maximize accumulated reward  

- **Semi-supervised learning**  
  - Combine many unlabeled samples with few labeled ones  

- **Active learning**  
  - Learn by querying an oracle for labels  

- **Learning to learn (Meta-learning)**  
  - Learn to construct better ML models  

- **Learning to rank**  
  - Rank relevant items for a query  
  - Examples: Netflix, web search, ad placement  

- And many more
